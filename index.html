ESP32 BCH Solo Mining
Assessment

CYD 2.8 / WROOM / S3 / C3 — Firmware, Pools & Reality Check
Research Active
BCH Pool Availability: Limited
NMMiner BCH: Confirmed Supported
SparkMiner BCH: BTC Only

YES — BCH solo mining on ESP32 CYD/WROOM is possible, but with hard constraints. BCH uses SHA-256d (same as BTC), so existing firmware works — the bottleneck is finding a solo pool that accepts low-difficulty connections from ESP32-class hardware. As of May 2026, NMMiner firmware (commercial, licensed) is the only CYD-native option with confirmed BCH support. NerdMiner V2 (open source) works IF you can identify a compatible low-diff BCH stratum pool — which has proven unstable in the community. SparkMiner (open source, highest hashrate) explicitly does NOT support BCH.

01

Hardware Compatibility

All three of your target boards share the same ESP32 core architecture (Xtensa LX6 or LX7 dual-core, 240MHz) and SHA-256d capability. BCH = SHA-256d — no algorithm incompatibility exists at the hardware level.

05

Fastest Path to BCH Mining — CYD 2.8

1

Identify Your CYD Display Driver

CYD ESP32-2432S028R comes in two display variants: ILI9341 and ST7789. Wrong firmware = screen corruption. Check your board's back label or silk screen. When in doubt, flash both and keep the one that displays correctly. NMMiner web flasher at flash.nmminer.com lists both options explicitly.

2

Get a BCH Wallet Address

Any non-custodial BCH wallet works. Electron Cash (open source, desktop) is the community standard. Your miner's worker name in stratum = your BCH address. You'll need this before flashing configuration.

3A

Path A: NMMiner (Paid, Easiest)

Purchase NMMiner license at nmminer.com. Flash via web flasher at flash.nmminer.com using Chrome/Brave. Select board: esp32-2432s028r-ili9341 or esp32-2432s028r-st7789. Configure via WiFi portal or built-in web dashboard. Set pool to NMMiner's BCH stratum, enter BCH address. BCH/DGB/XEC all confirmed supported per NMMiner dev team.

Pool: stratum+tcp://solobtc.nmminer.com:3333 | Password: x
3B

Path B: NerdMiner V2 (Free, Pool-Dependent)

Flash from GitHub releases: github.com/BitMaker-hub/NerdMiner_v2/releases. Use file ESP32-2432S028R_factory.bin for fresh install. Flash via ESPWebTool in Chrome. Connect to NerdMiner WiFi AP post-flash, configure BCH pool and BCH address. Pool must accept low-difficulty stratum. retromike.net BCH pool is the only community-confirmed option but has stability issues.

Pool: retromike.net (BCH port) | Password: x | Worker: your-BCH-address
4

Install CH340 USB Driver (if needed)

CYD boards use CH340 USB-serial chip. Without this driver, Windows won't recognize the COM port and flashing will fail. Download from wch.cn or search "CH340 driver Windows 10/11." Mac/Linux usually detect automatically. NMMiner community confirms this as the #1 first-flash failure point.

5

Boot Mode for Stubborn Boards

If flashing fails or upload stalls: unplug USB, hold BOOT button, plug USB back in, then release. This forces the ESP32 into download mode. Required on some CYD variants especially for factory/full-chip flash. After programming, press RESET or replug to boot into firmware.

Strategic assessment: BCH's ~200x lower difficulty meaningfully improves lottery odds compared to BTC solo mining on an ESP32. The block reward is higher in BCH units (6.25 vs 3.125) though BTC's USD price premium inverts this in fiat terms. For pure lottery probability on a hobbyist device, BCH is the rational target. Network difficulty adjusts every block on BCH (DAA), so this ratio fluctuates.
07

Known Issues & Community-Reported Failures

POOL INSTABILITY: As of community reports through late 2025, retromike.net BCH pool is the only confirmed NerdMiner-compatible BCH solo pool — and it has had sustained downtime periods. No stable, free, ESP32-compatible BCH solo pool is reliably operational 24/7 as of research date.
DISPLAY DRIVER CONFLICT: CYD 2.8 boards exist in two variants (ILI9341, ST7789). Flashing wrong firmware produces garbled display but does not brick the device. Reflash with correct driver variant.
POWER CYCLING: Community users reported mass power cycling across multiple ESP32 units after connecting to DigiByte pools. Cause was traced to pool protocol mismatches. Clean wipe + reflash resolved. If BCH pool causes instability, full flash erase recommended before switching.
NMMiner LICENSING: NMMiner firmware is not fully open source. License cost is per-device. The GitHub repo (NMminer1024/NMMiner) contains source but the lotto/BCH features may require active license. Community questions about self-hosting go unanswered.
SparkMiner BCH: Explicitly confirmed BTC-only in FAQ. "SparkMiner only supports Bitcoin (SHA-256d). Other coins use different algorithms." — this statement is technically inaccurate (BCH IS SHA-256d), but BCH support is not on the roadmap as of the research date. No GitHub issue or PR has successfully added BCH pool switching.
